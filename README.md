## 🎯 The Problem

Students face unprecedented pressure during their academic journey:

- **Lack of direction:** "What should I study today?" 
- **Information overload:** Juggling multiple subjects, deadlines, and expectations
- **Unmanaged stress:** No tools acknowledge the student's emotional state while studying
- **Generic advice:** One-size-fits-all study apps ignore individual circumstances
- **Social isolation:** New students don't know who to turn to when overwhelmed

**Current solutions focus on productivity (task lists) OR wellness (meditation apps), but never both together.**

---

## ✨ The Solution

**AI Study Mentor** integrates academic planning with emotional intelligence:

| Feature | What It Does | Why It Matters |
|---------|-------------|---|
| 🤖 **AI Mentor Chat** | Context-aware conversational AI that detects mood and adapts responses | Students get personalized guidance, not generic platitudes |
| 📋 **Daily Tasks** | Gamified, progressive task system based on a 90-day learning journey | Builds consistency through structured milestones and streaks |
| 📊 **Smart Dashboard** | Real-time visualization of progress, mood trends, and achievement | One central hub reduces decision fatigue |
| 🚨 **Panic Button** | Instant stress-relief intervention with grounding exercises | Acute anxiety gets immediate, actionable help |
| 🧠 **Expectation vs Reality** | Unique psychology-based module that compares goals vs. actual outcomes | Normalizes struggle and prevents perfectionism burnout |
| 👥 **Senior Comments** | Authentic advice from real students who've succeeded | Peer mentorship builds trust and relatability |
| 🏫 **Campus Guide** | Interactive directory of facilities, resources, and navigation | New students feel less lost and more connected |

## 🎯 Project Goal

The main goal of this project is to build an intelligent system that:

- collects student academic and behavioral data
- evaluates the student’s current condition
- generates a personalized daily plan
- adapts the plan based on stress and progress
- explains the reasoning using AI
- helps students stay organized and consistent

---

## 🧩 Problem Statement

Many students do not know what to study daily, especially when:
- exams are near
- time is limited
- weak subjects need attention
- stress is high
- motivation is low

Generic advice is usually not enough.  
A student needs a system that understands their current condition and gives a clear action plan.

This project solves that by turning student input into a personalized, adaptive study plan.

---

## ✨ Key Features

### 1. Personalized Study Plan
- Generates tasks based on student input
- Focuses on weak subjects and priorities
- Includes estimated time for each task

### 2. Stress-Aware Planning
- Reduces workload when stress is high
- Suggests lighter study sessions
- Adds breaks when needed

### 3. AI Mentor Chat
- Explains why a plan was generated
- Answers student questions
- Provides practical and concise guidance

### 4. Adaptive Replanning
- Updates the plan when the user changes their condition
- Recalculates priorities based on updated input

### 5. Context-Based Guidance
- Uses current subjects and topics
- Produces responses that are relevant to the student’s present study phase

### 6. Progress Tracking
- Stores study updates
- Can show recent plan history
- Helps the user monitor consistency
