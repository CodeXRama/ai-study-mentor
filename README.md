# 🧠 Adaptive AI Study Mentor with Stress-Aware Planning

A domain-specific AI mentor system that helps students make better daily study decisions based on academic performance, stress level, current subjects, available time, and study behavior.

This project is designed as a practical, web-based educational assistant that converts student inputs into a personalized study plan and then explains the plan using an AI mentor interface.

---

## 📌 Project Summary

Students often struggle with questions like:

- What should I study today?
- How do I manage my time?
- How do I study when I am stressed?
- Which topic should I prioritize first?
- How do I stay consistent every day?

This project addresses that gap by combining:

- rule-based evaluation logic
- AI-based explanation
- adaptive replanning
- stress-aware workload control
- context-based guidance

The system is not just a chatbot.  
It is a **personalized study mentor** that gives structured, practical, and relevant guidance.

---

## 🎯 Project Goal

The main goal of this project is to build an intelligent system that:

- collects student academic and behavioral data
- evaluates the student’s current condition
- generates a personalized daily plan
- adapts the plan based on stress and progress
- explains the reasoning using AI
- helps students stay organized and consistent

---

## 🧩 Problem Statement

Many students do not know what to study daily, especially when:
- exams are near
- time is limited
- weak subjects need attention
- stress is high
- motivation is low

Generic advice is usually not enough.  
A student needs a system that understands their current condition and gives a clear action plan.

This project solves that by turning student input into a personalized, adaptive study plan.

---

## ✨ Key Features

### 1. Personalized Study Plan
- Generates tasks based on student input
- Focuses on weak subjects and priorities
- Includes estimated time for each task

### 2. Stress-Aware Planning
- Reduces workload when stress is high
- Suggests lighter study sessions
- Adds breaks when needed

### 3. AI Mentor Chat
- Explains why a plan was generated
- Answers student questions
- Provides practical and concise guidance

### 4. Adaptive Replanning
- Updates the plan when the user changes their condition
- Recalculates priorities based on updated input

### 5. Context-Based Guidance
- Uses current subjects and topics
- Produces responses that are relevant to the student’s present study phase

### 6. Progress Tracking
- Stores study updates
- Can show recent plan history
- Helps the user monitor consistency
